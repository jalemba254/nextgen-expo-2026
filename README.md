# NextGen Expo 2026

## Project Overview
NextGen Expo is a digital event management system designed to simplify event administration.

## Technologies Used
- Google Apps Script
- Google Sheets
- HTML
- CSS
- JavaScript

## Key Features
- Exhibitor registration
- Payment tracking and verification
- Visitor registration
- Booth management
- Attendance management
- Digital receipts
- QR code check-in
- Administrative dashboard
