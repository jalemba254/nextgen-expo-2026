# NextGen Expo 2026 — Event Management System

## Overview

NextGen Expo 2026 is an event management system developed using Google Apps Script, Google Sheets, and HTML. It is designed to support exhibitor registration, payment tracking, administrative operations, and payment receipt generation.


## Dashboard Preview

![NextGen Expo Admin Dashboard](nextgen-dashboard.png)


## Key Features

- **Exhibitor Registration:** Collects and manages exhibitor registration information.
- **Payment Tracking:** Supports payment-related record management.
- **Admin Dashboard:** Provides an administrative interface for managing event operations.
- **Payment Receipts:** Includes a dedicated receipt page.
- **Google Sheets Integration:** Uses Google Sheets as the system's data store.
- **Web Interface:** Uses HTML and Google Apps Script to deliver application functionality.

## Technology Stack

- Google Apps Script
- Google Sheets
- HTML
- JavaScript

## Architecture

The application uses Google Apps Script to process server-side operations and communicate with Google Sheets. HTML and JavaScript provide the user interface.

## Security and Configuration

Administrator credentials should be configured securely and must not be hard-coded into source files. Access to the deployed application and its data should be restricted appropriately.
